# Цифровая архитектура промышленного холдинга

15-минутный доклад для сотрудников крупного промышленного энергохолдинга: что такое современная цифровая архитектура, какие тренды и требования она обязана закрывать, как выглядит цель при легаси и жёстком технологическом контуре, какими этапами идти и что меняется в работе людей.

Это не платформа цифровизации и не каталог систем. Это рабочий слайд-доклад, который можно открыть на проекторе, плюс полный текст «читать вслух» и одностраничная памятка.

## Как запустить

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Доклад откроется на [http://127.0.0.1:43217](http://127.0.0.1:43217).

Продакшен:

```bash
npm run build
npm start
```

## О чём доклад

1. **Зачем холдингу архитектура.** Второй контур конкуренции — скорость решения на достоверных данных, а не только мощность и топливо.
2. **Реальность.** ДЗО, зоопарк ERP, АСУ ТП со сроком жизни 15–25 лет, КИИ и импортозамещение. Легаси — швы (Excel, файлы), а не контроллер на станции.
3. **Семь доменов.** Бизнес, приложения, данные, интеграция, платформа, безопасность, операционная модель.
4. **Тренды.** IT/OT без смешения сетей, продукты данных, предиктивный ТОиР, промышленный ИИ, внутренняя платформа, заменяемость компонентов.
5. **Must / Should / Win.** Не потерять право производить, не проиграть в эффективности, купить преимущество.
6. **Целевая слоистость.** L0–L2 → L3 → OT DMZ → корпоративный контур → холдинговые продукты. Данные вверх, команды вниз — только через шлюзы.
7. **Этапы.** 90 дней инвентаризации и совета с вето, затем связность, данные, платформа, домены, ИИ, продуктовая модель.
8. **Люди.** Не заказываем системы — развиваем способности холдинга.

## Для кого

Руководители ДЗО и корпоративного центра, ИТ, АСУ ТП, главные инженеры, ИБ, владельцы процессов. Язык — производственный, без стартап-лозунгов.
