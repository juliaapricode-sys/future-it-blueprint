# Цифровая архитектура промышленного холдинга

15-минутный доклад для руководителей и специалистов промышленного энергетического холдинга: состав современной архитектуры, целевые слои, корпоративное хранилище данных, портал данных и управление данными, порядок оценки технологий, смещение ролей информационных технологий и бизнес-пользователей, этапы перехода.

Приложение включает полноэкранные слайды, полный текст для чтения вслух и памятку.

## Как запустить

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Доклад: [http://127.0.0.1:43217](http://127.0.0.1:43217).

Продакшен:

```bash
npm run build
npm start
```

Dev-сервер слушает `0.0.0.0`. В `next.config.ts` разрешён origin `127.0.0.1`.

## Как показывать

| Клавиша | Действие |
| --- | --- |
| `→` `пробел` `J` | Следующий слайд (таймер 15:00 запускается автоматически) |
| `←` `K` | Предыдущий слайд |
| `N` | Заметки докладчика |
| `T` | Пауза / продолжение таймера |
| `F` | Полный экран |
| `Esc` | Обзор слайдов |
| `?` | Справка |

Дополнительные страницы:

- `/script` — связный текст на 15 минут
- `/handout` — памятка после доклада

## Содержание

1. Назначение архитектуры: второй контур конкуренции — скорость решения на достоверных данных.
2. Исходные условия: унаследованный ландшафт и технологический контур.
3. Семь доменов архитектуры.
4. Целевые слои (включая Data Portal, Data Governance, Corporate Data Warehouse).
5. Почему данные собирают в одном месте — согласованная копия после шлюза, не смешение сетей IT и OT.
6. Тренды и технологии: гипотеза ценности, ограниченный пилот, осознанное инвестирование.
7. Must / Should / Win.
8. Смещение ролей: бизнес формирует MVP, ИТ обеспечивает платформу, интеграции и информационную безопасность.
9. Этапы перехода, подготовка Холдинга, решения на 90 дней.

Английские термины на слайдах сопровождаются пояснением назначения.
