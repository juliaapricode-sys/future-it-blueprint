# Цифровая архитектура промышленного холдинга

15-минутный доклад для руководителей и специалистов промышленного энергетического холдинга: состав современной архитектуры, целевые слои, корпоративное хранилище данных, портал данных и управление данными, порядок оценки технологий, смещение ролей информационных технологий и бизнес-пользователей, этапы перехода.

Сайт можно **загрузить на обычный хостинг Timeweb** как набор HTML-файлов. GitHub и Node.js на сервере не требуются.

Готовые выгрузки 13 слайдов 16:9: `Holding-digital-architecture.pptx` и `Holding-digital-architecture.pdf`.

## Как разместить на сервере Timeweb на отдельном порту

Текущий сайт на портах 80 и 443 не трогаем. Доклад слушает **свой порт 43217** из отдельного каталога `/var/www/holding-architecture`.

Нужна сборка **без** префикса пути: страница открывается как `http://IP:43217/`, а не `/holding-architecture/`.

1. Соберите архив:

```bash
npm run pack:port
```

Появится `holding-architecture-port.zip` — внутри папка `holding-architecture/` с полной кинематографической страницей.

2. На сервере (консоль в панели Timeweb или SSH), **не** распаковывая в корень текущего сайта:

```bash
sudo mkdir -p /var/www/holding-architecture
sudo unzip -o holding-architecture-port.zip -d /tmp
sudo rsync -a --delete /tmp/holding-architecture/ /var/www/holding-architecture/
```

3. Добавьте отдельный сайт nginx (файл уже в репозитории: `deploy/nginx-holding-architecture-43217.conf`):

```bash
sudo cp deploy/nginx-holding-architecture-43217.conf /etc/nginx/sites-available/holding-architecture-43217.conf
sudo ln -sfn /etc/nginx/sites-available/holding-architecture-43217.conf /etc/nginx/sites-enabled/holding-architecture-43217.conf
sudo nginx -t && sudo systemctl reload nginx
```

Конфигурация только `listen 43217`. Блоки существующего сайта не редактируются.

4. Откройте порт:

- на сервере: `sudo ufw allow 43217/tcp` (если включён ufw);
- в панели Timeweb: [Сети → Firewall](https://timeweb.cloud/my/firewalls) — входящий TCP **43217**, если к серверу привязан разрешающий файрвол. Если файрвол не создан, панель его не фильтрует.

5. Ссылка для коллег: `http://IP-сервера:43217/`

Node.js на сервере не нужен: nginx отдаёт статику. Если nginx нет, поставьте его (`sudo apt install nginx`) — это не заменяет сайт на 80, пока вы не меняете его конфигурацию.

Если есть SSH с этой машины: `TIMEWEB_HOST=IP npm run deploy:timeweb-port`.

## Как запустить локально

```bash
npm install
npm run dev
```

Доклад: [http://127.0.0.1:43217](http://127.0.0.1:43217).

Проверка той же сборки, что уйдёт на Timeweb:

```bash
npm run build
npm start
```

## Содержание доклада

1. Назначение архитектуры: второй контур конкуренции — скорость решения на достоверных данных.
2. Исходные условия: унаследованный ландшафт и технологический контур.
3. Семь компонентов архитектуры.
4. Целевые слои, включая портал искусственного интеллекта, маркетплейс сервисов, протокол контекста модели и программные интерфейсы.
5. Почему данные собирают в одном месте — согласованная копия после шлюза, не смешение информационного и операционного контуров.
6. Тренды и технологии: гипотеза ценности, ограниченный пилот, осознанное инвестирование.
7. Обязательный, необходимый уровни и уровень преимущества.
8. Смещение ролей: бизнес формирует минимально жизнеспособный продукт, информационные технологии обеспечивают платформу, интеграции и информационную безопасность.
9. Этапы перехода, пакет стратегий и политик, первые решения.
