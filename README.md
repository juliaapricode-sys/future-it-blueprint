# Цифровая архитектура промышленного холдинга

15-минутный доклад для руководителей и специалистов промышленного энергетического холдинга: состав современной архитектуры, целевые слои, корпоративное хранилище данных, портал данных и управление данными, порядок оценки технологий, смещение ролей информационных технологий и бизнес-пользователей, этапы перехода.

Сайт можно **загрузить на обычный хостинг Timeweb** как набор HTML-файлов. GitHub и Node.js на сервере не требуются.

Готовые выгрузки 13 слайдов 16:9: `Holding-digital-architecture.pptx` и `Holding-digital-architecture.pdf`.

## Как показать коллегам с Timeweb

Доклад на Timeweb — **та же кинематографическая веб-страница**, что и в разработке: полноэкранные сцены, шторы кадра, стекло, шина, анимация ken-burns. Это статическая HTML-сборка, Node.js на сервере не нужен. На уже работающем сайте она кладётся в отдельный каталог `holding-architecture/`. Корневой `index.html` не заменяется.

1. `npm run pack:html` — архив `holding-architecture-html.zip`.

2. Распакуйте архив в корень сайта. Появится только каталог `holding-architecture/`.

3. Ссылка: `https://ваш-домен.ru/holding-architecture/`

Управление слайдами: стрелки, пробел, J/K; F — полный экран; Esc — обзор.

Локально та же страница: `npm run build` и `npm start` (порт 43217) или `npm run start:html` (порт 43218).

## Как запустить локально

```bash
npm install
npm run dev
```

Доклад: [http://127.0.0.1:43217](http://127.0.0.1:43217).

Проверка той же сборки, что уйдёт на Timeweb:

```bash
npm run build
npm start
```

## Содержание доклада

1. Назначение архитектуры: второй контур конкуренции — скорость решения на достоверных данных.
2. Исходные условия: унаследованный ландшафт и технологический контур.
3. Семь компонентов архитектуры.
4. Целевые слои, включая портал искусственного интеллекта, маркетплейс сервисов, протокол контекста модели и программные интерфейсы.
5. Почему данные собирают в одном месте — согласованная копия после шлюза, не смешение информационного и операционного контуров.
6. Тренды и технологии: гипотеза ценности, ограниченный пилот, осознанное инвестирование.
7. Обязательный, необходимый уровни и уровень преимущества.
8. Смещение ролей: бизнес формирует минимально жизнеспособный продукт, информационные технологии обеспечивают платформу, интеграции и информационную безопасность.
9. Этапы перехода, пакет стратегий и политик, первые решения.
