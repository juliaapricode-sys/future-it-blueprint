# Брендбук доклада

Визуальный и речевой стандарт проекта «Цифровая архитектура промышленного холдинга». Экранная версия: `/brand`.

Источник цвета в коде: `src/app/globals.css`.

## Характер

Промышленный энергетический холдинг. Кадр — ситуационный контур: тёмный фон, стекло, тонкая шина, уголки индикации. Не стартап, не развлекательный интерфейс, не «приветствие в приложении».

## Цвет

| Имя | Роль | OKLCH (код) | Ориентир HEX |
| --- | --- | --- | --- |
| Чернила | Фон сцены | `oklch(0.13 0.028 250)` | `#0B1220` |
| Бумага | Основной текст | `oklch(0.96 0.01 230)` | `#F4F0E6` |
| Циан | Информационные контуры | `oklch(0.82 0.11 195)` | `#5ED4E8` |
| Золото | Решение и данные | `oklch(0.84 0.12 85)` | `#E0B25A` |
| Фиолет | Технологический контур | `oklch(0.72 0.16 300)` | `#B48CF0` |

Карточки — стекло: полупрозрачный тёмный слой, обводка циана, размытие. Уголки HUD — L-образные штрихи. Шина (busbar) — градиент фиолет → циан → золото.

## Шрифт

- **Unbounded** — заголовки.
- **IBM Plex Sans** — текст, кириллица обязательна.
- **IBM Plex Mono** — номера, кикеры, служебные подписи.

В PowerPoint: геометрический гротеск для заголовка, Calibri или IBM Plex Sans для текста, Consolas для моноширинного.

## Речь

- Формальный русский, без сленга.
- На слайдах не оставлять необъяснённых латинских сокращений.
- «Компании», не «ДЗО».
- «Архив технологических параметров», не жаргон контура.
- Не обещать календарные границы, которых нет в решении.
- «Холдинг» с заглавной, когда речь о адресате доклада.

## Композиция

- Сцена 16:9, полноэкранно.
- Кикер моноширинным цианом над заголовком.
- Фон — сцена по смыслу кадра, затемнение, текст на стекле.
- На узком экране — одна колонка; слайды листаются свайпом и кнопками «Назад / Далее».
